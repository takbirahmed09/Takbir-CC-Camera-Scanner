# 🛡️ Takbir CC-Camera & Network Scanner v1.0

A professional network and CC-Camera scanner tool designed for advanced network enumeration. Developed with a hacker-themed UI using Python.

---

## 🚀 Installation & Usage Guide (Termux / Linux)

Run the following commands one by one in your terminal to install and launch the tool. You can click on any code block to copy it instantly.

### 1. Update and Install Dependencies
```bash
pkg update && pkg upgrade -y
pkg install python nmap git -y
```

## 2. Install Python Required Libraries
```bash
pip install rich python-nmap
```

## 3. Clone the Repository
```bash
git clone https://github.com/takbirahmed09/Takbir-CC-Camera-Scanner
```

## 4. Navigate to the Directory
```bash
cd Takbir-CC-Camera-Scanner
```

## 5. Run the Script
```bash
python takbir_cc_camera_scan.py
```


# 🛠️ Features

​WiFi Device Scanning: Detects all connected devices, MAC addresses, and vendors on the network.
​CC-Camera Detection: Scans specific open ports and signatures (80, 554, 8000, 37777, etc.) to discover IP cameras, DVRs, and NVRs.
​Rich UI: Beautifully formatted tables and terminal banners.
